Shorts Uploader Privacy Policy

Last updated: November 8, 2026

Shorts Uploader is a private tool used by a single channel owner to upload their own videos to their own YouTube channel and TikTok account through the YouTube Data API and the TikTok Content Posting API. It is not offered to the public.

Data the tool accesses

With the owner's consent via Google OAuth, the tool can upload videos and read basic information about the owner's own YouTube channel (titles, upload status, statistics).

How data is used and stored

  • Data is used only to upload and manage the owner's own videos.
  • OAuth tokens are stored locally on the owner's computer and never shared.
  • No data is sold, shared with third parties, or used for advertising.

TikTok

With the owner's consent via TikTok Login Kit, the tool reads basic profile info and posts the owner's own videos to their own TikTok account. TikTok access tokens are stored only on the owner's computer. See the TikTok Privacy Policy.

YouTube and Google

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.

Deleting data

Revoking access and deleting the local token file removes all data held by the tool.
